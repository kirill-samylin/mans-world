# Man's World — сайт и презентация

Презентация предложения по сайту барбершопа Man's World и прототипы самого сайта.

- `mans-world-pitch.dc.html` — презентация. Открывается с корня сайта. Два режима просмотра, переключатель в правом верхнем углу:
  - «Слайды» — по одному слайду, стрелки ←/→ или тап по краям экрана;
  - «Лента» — все слайды подряд, прокрутка сверху вниз как PDF. Прямая ссылка: `?view=scroll`.
  Выбранный режим запоминается в браузере.
- `mans-world-v3.dc.html` — основной прототип сайта (текущая версия).
- `Man's World.dc.html`, `Man's World v2.dc.html` — предыдущие версии прототипа.
- `variants/` — альтернативные варианты оформления v3 (editorial, grid, silver).
- `assets/`, `uploads/` — логотип, фотографии интерьера и работ.
- `support.js`, `deck-stage.js`, `mw-live.js` — рантайм для `.dc.html` страниц и слайдов.

Сайт публикуется через GitHub Pages из ветки `main`.
